# 05 — Canvas Builder

## Visual spec
- Hairline grid canvas background.
- Left Build Block rail:
  - Rules grid (VALIDATE, SPLIT, IF, CONTAINS, MATCH, COMPARE)
  - Sequence management list
- Main canvas with sharp framed nodes and dashed connectors with arrowheads.

## Node spec
- Sharp frame, thin stroke, crisp typography.
- Compact status badge line (`/start`, `/true`, etc.).

## Connector spec
- Dashed lines with consistent cadence.
- Arrow markers on target endpoints.

## Interaction roadmap
- V1: static composition + faux controls (zoom/template/save).
- V2: pan/zoom camera and minimap.
- V3: drag nodes + snap-to-grid + link editing.
