# 00 — Overview

## What this UI is
OpenClaw Mission Control is an **operations/governance interface** for agent systems, not a marketing front-end. It is optimized for runtime visibility and control across boards, tasks, approvals, gateways, and agents.

## Principles
- Instrument Brutalism visual language (dark, sharp, framed).
- Observability-first hierarchy over decorative UI.
- Reusable modules with backend-contract safety.
- Event-driven surfaces for live operations.

## Non-goals
- Generic rounded SaaS dashboard aesthetics.
- Heavy glassmorphism and soft pastel cards.
- Route/IA breakage or API contract drift.

## Navigation and major surfaces
- Dashboard
- Activity
- Boards / Board Groups
- Approvals
- Tags
- Skills
- Organization
- Gateways
- Agents
- Extreme Events
- Workflow Builder
- Model Graph
